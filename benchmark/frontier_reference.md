# 前沿上下文压缩方案参照(论文公开数据)

> 来源:联网调研(2026-08-20),数据取自论文公开结果,未经本地复现
> 用途:作为 FF-Compactor 的前沿参照定位,非同口径实测对比

## 一、方案全景

### 显式压缩(删内容,与 FF-Compactor 同类)

| 方案 | 粒度 | 核心机制 | 论文公开数据 | 对比意义 |
|------|------|---------|-------------|---------|
| LLMLingua(ICLR'24) | token | 困惑度剪枝 | LongBench 准确率降 2-4%,压缩 80%+ | ✅ 已本地实测(200 条:0.689/0.828) |
| **LLMLingua-2**(ACL Findings'24) | token | 数据蒸馏 + token 分类器(XLM-RoBERTa) | 比 v1 快 3-6 倍;LongBench-E 4x 时 EM ~33 | 同赛道最强基线(模型 gated 未实测) |
| Selective Context | 句子 | LLM 打分选句 | 优于朴素截断 | ✅ 已本地近似实测 |
| RECOMP(ICLR'24) | 句子 | 监督摘要器 + 压缩-再检索 | 优于摘要/截断 | ✅ 已本地近似实测 |
| **FF-Compactor(本文)** | 句子 | 保真度门控 + 贪心选句 | 0.708 压缩 / 0.996 保真(340 样本) | — |

### 隐式压缩(压成向量)

| 方案 | 机制 | 论文公开数据(LongBench-E EM@4x) |
|------|------|--------------------------------|
| ICAE | 上下文自编码器 | ~49 |
| Beacon | 压缩 token 流式 | 部分 QA 被 AdmTree 超越 20 分 |
| Compression-Tokens | 双向压缩 token | ~51-53 |
| Mean-Pooling | 平均池化压缩 token | ~55-56 |
| xRAG / COCOM | 检索嵌入 / 上下文嵌入 | — |

### 前沿混合(2025-2026)

| 方案 | 机制 | 亮点 |
|------|------|------|
| **AdmTree**(NeurIPS 2025) | 自适应语义树 + gist token | LongBench 超越基线 10%+,QA 超越 Beacon 20 分 |
| **SeleCom**(arXiv 2026) | 查询条件软压缩选择器 | 82× 极端压缩,RAG 场景平行基线 |

## 二、FF-Compactor 定位

| 维度 | 定位 |
|------|------|
| 类别 | **显式句子级压缩**(与 LLMLingua/Selective/RECOMP 同赛道) |
| 差异化 | **保真度门控(显式约束)+ 免训练 + 42ms CPU 无需 GPU** |
| 对比实测 | 已胜过 LLMLingua-7B(保真 0.996 vs 0.828)与摘要(0.796) |
| 与隐式方案 | 粒度不同,隐式可到 4x-128x 极端压缩但需训练;本文为免训练工程方案 |
| 待补 | LLMLingua-2(模型 gated)、AdmTree/SeleCom(需复现) |

## 三、结论

FF-Compactor 在**免训练显式压缩**赛道处于领先(同量级实测对比 LLMLingua-7B 保真度 +17pp);
与需训练的隐式/前沿方案(ICAE/AdmTree/SeleCom)属不同赛道——若论文投稿,可在相关工作
中对比其公开数据并指出"免训练 + 可解释门控"的差异化贡献。
